# RFC Index

## Conventions

| Rule | Value |
|------|-------|
| Location | `docs/rfc/` |
| Naming | `NNNN-short-slug.md` (zero-padded, 4 digits) |
| Status values | `Draft` · `Under Review` · `Approved` · `Superseded` · `Rejected` |
| Archive | `docs/rfc/completed/` · `docs/rfc/rejected/` |

## Required sections

Every RFC must include:

1. **Summary**
2. **Motivation**
3. **Proposal**
4. **Tasks**
5. **Status**
